# UrHomi · 我的留学房源

UrHomi 是本地运行的租房收藏网站和 Chrome 插件。浏览 Rightmove / Zoopla 出租详情页，点击「保存到我的房源」，在自己的工作台查看照片、原始报价并记录联系进度。

当前版本：**0.6.0**。本项目是个人使用的本地原型，尚未部署为公网或多用户服务。

## 快速开始

需要 Python 3.9+ 与 Chrome 116+，无需安装第三方 Python 包。

```sh
git clone https://github.com/KylaSun/UrHomi_Your-Housing-Desicions.git
cd UrHomi_Your-Housing-Desicions
python3 apps/server/server.py
```

打开 <http://127.0.0.1:8765>。macOS 也可以双击「启动 UrHomi.command」，并保持终端窗口运行。

## 安装 Chrome 插件

1. 打开 `chrome://extensions`，开启开发者模式。
2. 点击「加载已解压的扩展程序」，选择本仓库的 `apps/extension` 目录。
3. 先启动本地服务，再在插件点击「连接本机工作台」，通常无需手动复制连接密钥。
4. 打开 Rightmove / Zoopla 的单套出租详情页，点击页面右下角「保存到我的房源」。
5. 回到工作台刷新，在「我的房源」查看收藏。

更新代码后，在扩展管理页重新加载 UrHomi，并刷新原房源页面。旧收藏如只有一张照片，重新打开原房源页并通过插件读取，即可补充当前可识别的相册。

## 功能

- 自动识别支持的出租详情页，一键读取与保存；手动粘贴链接作为备选。
- 卡片保留照片、标题、地址、原始租金及周期、卧室数、平台来源与原始 URL。
- 卡片和详情相册支持滑动、左右按钮、聚焦后方向键浏览。
- 从原页面 JSON-LD、图片微数据、相册和公开图片元数据提取照片，优先使用原页面提供的大尺寸候选。没有照片时显示占位。
- 按平台房源 ID 去除链接追踪参数并去重，同一项目重复保存保留原记录和联系状态。
- 保存需求、对比费用、准备英文咨询与记录回复；复制咨询不会自动标记为已联系。
- 可选 OpenAI 咨询功能；未配置时仍可使用本地模板。调用费用及数据发送需在界面主动确认。

## 数据与权限

数据库保存在本机 `data/urhomi.sqlite3`，被 Git 忽略。更新时备份并保留该目录。连接密钥不可公开；OpenAI API 密钥不进入源码和版本库。

服务只绑定 `127.0.0.1`，不要直接暴露到公网。照片由浏览器从原图片地址加载，未重新托管。显示来源和版权不代表获得转载授权，公开或商业使用前需取得相应授权。

本项目尚未接入 Rightmove / Zoopla 商业数据 API，不绕过安全验证。平台改版、懒加载、图片权限或缺少元数据可能导致照片不完整。房源价格、可租状态及合同条件请返回原网站核实。

## 验证

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/extension.test.cjs
```

启动服务后可访问 <http://127.0.0.1:8765/integration-test> 运行浏览器中的合成房源提取测试。测试使用独立临时数据库，不联系房东、不调用真实 OpenAI。

本次验收：22 项服务测试、17 项浏览器提取测试和4组插件模拟测试通过。完整说明见 [CHANGELOG.md](CHANGELOG.md)。

## 项目结构

- `apps/web`：中文房源工作台。
- `apps/extension`：Chrome 插件。
- `apps/server`：本机服务及可选咨询功能。
- `tests`：服务、房源提取与插件交互测试。
